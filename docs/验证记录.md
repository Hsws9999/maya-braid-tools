## 集成验收范围

同一份 `tests/integration_maya.py` 在三个 Maya 版本上各运行一次完整测试，包括：多对象创建与重复创建、创建撤销重做、连续 CV 编辑、批量参数和撤销、两种密度模式、局部尺寸与旋转曲线、批量曲线编辑范围、模型与导向精度独立、重命名与父级变换和非均匀缩放、根部方向连续性、两种历史模式的 Maya 原位重建、工具重建与重新关联、静态导向及根面与烘焙、保存重开、无效或丢失输入、精度上限与恢复、零尺寸根面提取的原子性、20 条辫子的独立更新。

性能测试为 20 条默认辫子场景，仅修改其中一条的 CV，评估并读取其三股网格；其他 19 条未被标脏、输出未变。预热后测量：

这是本机依赖图计算与数据读取时间，不含视口绘制，不代表其他设备的帧率承诺。

## 模块和 Qt 兼容

`tests/module_qt_smoke.py` 验证了以下安装布局：用户模块目录顶层的 `BraidTools.mod` 指向同级 `BraidTools` 文件夹。三个版本均自动发现模块、导入该目录的 Python 脚本、加载对应年份的 `.mll`。

三个版本均完成离屏面板构建、参数编辑与撤销、Ramp 绘制及鼠标编辑、对话框执行接口测试。Qt6 测试中的兼容鼠标事件构造函数产生弃用提示，退出时还有 `MObject` 包装清理提示；测试进程退出码均为 0。此项不等于真实 Maya 停靠、视口鼠标拖动或长期运行验收。

隔离测试必须先建立 QApplication 再初始化 Maya，避免 Qt 应用对象类型冲突。不要将测试脚本直接在已有 Maya 会话中执行。

## 发布边界

本地开发节点 ID 保持为 `0x0007B7A1`。公开发布构建的两项拒绝规则已验证：未明确确认注册 ID 会拒绝；确认后仍使用默认开发 ID 也会拒绝。本次没有取得或虚构注册 ID。学习安装包沿用已验证的开发二进制，并明确标注未注册 ID；这不构成官方豁免，也不保证与所有第三方插件兼容。

本次没有验证 Maya 2023/2024、macOS/Linux、跨大版本场景互读、真实 XGen Description、UE 导出、长时间运行或不同硬件表现。三个年份分别保存重开成功，不表示高版本 Maya 场景能直接由低版本打开。

`validation_summary.json` 记录通过状态与相应源码、插件摘要，不含测试机器的用户名或工作目录。


## 直接安装版补充验证（2026-11-06）

- 安装核心的 18 项标准库测试通过：新安装、同内容重复安装不写入、已有不同内容保护、缺失或损坏包预检、中文与空格路径、交叉目录及清单越界拒绝、复制中断和描述文件竞争时的回滚。
- 使用实际安装器在三个独立临时用户目录完成安装，三版 Maya 均自动发现模块、加载匹配插件、构建离屏面板，并通过参数撤销、Ramp 编辑和绘制检查。
- 三版均在中文与空格目录下完成插件加载、生成模型和 27 条源导向、中文场景文件保存重开。
- 测试只使用隔离目录和进程，未操作已有交互 Maya。真实鼠标拖放、工具架重启后的显示与用户视觉验收不在本轮自动测试范围内。
- Maya 2025/2026 的本机 mayapy 命令行存在中文参数解码差异，因此测试报告路径从 Unicode 环境变量读取；插件本身的中文安装路径已单独验证。

安装后当前会话使用绝对路径加载脚本和对应插件，不依赖 Maya 动态加载相对模块目录。三个版本的即时激活、插件来源和生成功能检查通过；该检查替代了界面弹窗与工具架操作，因此不宣称工具架持久化的真实 GUI 验收。Shelf 保存失败和拖放缓存来源的两个回归检查已通过。
