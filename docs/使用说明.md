# BraidTools 使用说明

本文对应 1.0.3 学习预览版，采用 MIT 许可证。完整安装包包含 Windows Maya 2022、2023、2024、2025、2026 的插件，无需自行编译。**新增 2023／2024 仅编译通过，属于尚未完成 Maya 主机和 GUI 验证的兼容预览。** 版本状态以[项目首页](../README.md)为准。

**[下载完整学习预览安装包](https://github.com/Hsws9999/maya-braid-tools/raw/refs/heads/main/downloads/BraidTools1.0.zip)**。请下载这个 ZIP，而不是把 GitHub 的 Code → Download ZIP 源码快照当成插件安装包。

## 环境与安装方式

适用平台为 Windows x64。Maya 2022、2025、2026 保留原有独立构建；三版此前各通过 18 项隔离功能验收，以及模块自动发现、完整面板构建和离屏 Ramp 编辑等补充检查，本次未重跑这些 Maya 测试。新增 2023、2024 已分别编译，但本机未安装两版主程序，加载、Python/Qt 和功能未验证。Maya 2022 必须使用 Python 3 模式。当前多版本包的真实 GUI 拖动、视口交互与长时间运行尚未逐版复验。

三版还在含中文和空格的隔离目录中验证了模块发现、实际插件加载、27 条导向生成和中文场景路径保存重开，均通过。不要求全英文路径；未承诺所有任意 Unicode 字符组合均可用。

每个年份使用 `plug-ins/<年份>/braidTools.mll`。不要把其他年份的 `.mll` 复制或改名到缺失的目录中。Python 面板自动使用 Maya 自带的 PySide2／PySide6。

### 推荐：拖入安装器

1. 下载完整安装 ZIP，解压整个文件夹，保留 `scripts`、`plug-ins` 等子目录。
2. 打开 Maya，将解压后的 `BraidTools_Install.py` 拖入视口。不要在 ZIP 压缩包内部直接打开脚本。
3. 在安装窗口核对目标目录和 Shelf 影响后点击“安装”；Maya 2023／2024 的同一窗口会额外显示兼容预览说明。如果 Maya 提示脚本安全许可，确认来源后按提示处理。首次正常安装会打开面板，并添加 **BraidTools** 工具架上的**金色麻花辫图标**，以后点击该图标即可使用。已有工具架和按钮保持原样，不自动替换旧图标。

安装器使用 Maya 返回的用户目录，将完整运行文件放入 `modules/BraidTools`，在 `modules` 顶层建立 `BraidTools.mod`，并保存专属 Shelf 按钮。通常路径为 `Documents/maya/modules`。不需要管理员权限，不修改 `Maya.env`、`userSetup.py` 或系统环境变量。

安装影响限于这些插件文件、模块登记和专属 Shelf 按钮。相同内容、由本安装器管理的完整安装可重复运行，不再次复制文件；不同版本、不完整安装或非本安装器管理的同名目录会被拒绝覆盖。本版本不自动升级或卸载已有包。

若当前会话已经加载其他目录的脚本、插件或模块，安装器会完成磁盘安装，提示保存工作并重启 Maya；重启后从原解压目录再次拖入 `BraidTools_Install.py`，完成打开和 Shelf 创建。它不会强行卸载当前包。若已有同名用户工具架或 `shelf_BraidTools.mel`，会保留该内容，按提示拖入已安装目录的 `BraidTools_Open.py` 打开即可。

典型安装位置如下：

```text
Documents/maya/modules/
├── BraidTools.mod
└── BraidTools/
    ├── BraidTools_Open.py
    ├── icons/
    ├── scripts/
    │   └── braidtools/
    └── plug-ins/
        ├── 2022/braidTools.mll
        ├── 2023/braidTools.mll
        ├── 2024/braidTools.mll
        ├── 2025/braidTools.mll
        └── 2026/braidTools.mll
```

“文档”被重定向或使用了自定义 `MAYA_APP_DIR` 时，以 Maya 返回的用户目录为准。安装路径不必与本示意图完全相同。以后启动 Maya 时会发现已安装的模块；面板通过 Shelf 按钮主动打开。

也可以在 Script Editor 的 Python 页签运行以下命令，加载对应插件并打开面板：

```python
import braidtools
braidtools.show()
```

可编辑场景依赖 `braidToolsGenerator`。重新启动后，先打开工具，再打开含该节点的场景。

### 手动安装

需要手动管理插件时，将完整包放入实际 Maya 用户目录的 `modules/BraidTools`，再把包内 `BraidTools.mod` 复制到 `modules` 顶层，与文件夹并排。该文件中的 `./BraidTools` 相对于顶层 `.mod` 所在目录解释。重启 Maya 后运行上面的打开命令；手动复制不会自动添加 Shelf 按钮。

`C:/Program Files/Autodesk/Maya2026/modules` 也是 Maya 2026 的有效模块目录。本安装器使用用户目录，便于多个 Maya 年份共用并避免程序目录写入权限问题。

### 临时试用

将完整包里的 `BraidTools_Open.py` 拖到 Maya 视口。它按当前 Maya 年份寻找 `.mll`，为本次会话添加脚本路径并打开面板。重启后需再次打开，不构成长期模块安装。

如果当前会话已经从另一个目录导入 BraidTools，工具会提示冲突。保存工作并重新启动 Maya，再打开目标包，避免混用新旧脚本和二进制。Maya 的脚本安全提示应在确认来源后由用户处理。

### 更新与停用

安装器遇到已有包时，以具体提示为准。需要替换旧安装时，保存工作并关闭相关 Maya，把旧 `BraidTools` 文件夹和顶层 `BraidTools.mod` 备份到模块搜索目录之外，再在 Maya 中安装完整新包。不要在插件已经加载时覆盖 `.mll`。

停用时关闭 Maya，将顶层 `BraidTools.mod` 与 `BraidTools` 文件夹一起移出模块搜索目录，并按需要删除专属 Shelf 按钮。只改 `.mod` 扩展名不是可靠的停用方式。仍含生成节点的场景需要保留匹配插件，或先保存导向与烘焙模型的独立副本。

### 学习预览节点 ID

本包使用未注册开发 ID `0x0007B7A1`。它可能与使用同一 ID 的其他插件发生冲突；遇到冲突时停止同时加载该组合，不要随意改一个数字绕过。未来更换注册 ID 时需要验证已有场景迁移，不能假定直接替换兼容。说明见 [NOTICE.txt](../NOTICE.txt)。

## 生成与编辑

选择一条或多条开放 NURBS 曲线，点击“从所选曲线创建”。一条路径产生一个独立生成节点、一个资产组和三股模型。再次对同一条路径创建时，会定位已有资产。

选择主曲线、生成模型或资产组，面板读取对应参数。多选时，只把当前操作的参数写入所选辫子，保留其他参数的差异。关闭面板后，几何仍由 Maya 依赖图计算。

移动或缩放主曲线控制辫子路径。输出资产组是坐标容器，变换会被节点补偿；需要整体移动时，移动主曲线，或将路径与输出放到共同父组下。不要单独移动生成股的子变换节点。

支持 Maya 原位 Rebuild Curve 和工具内重建。若重建改变了路径，辫子也会跟随变化；重建不承诺保留原形。关联依据源对象身份维护，不依赖名称猜测。删除源对象后，选择资产并点击“重新绑定路径…”，再指定新的开放曲线；弹窗会固定正在编辑的资产。

创建、删除、一次参数操作、工具重建、重新绑定、导向提取和烘焙均可撤销。一次批量操作按一次撤销处理。

### 删除误建的辫子

在面板上方列表选择要移除的条目，再点击列表旁的“删除所选辫子…”。Ctrl/Shift 可多选；确认窗口会列出数量和资产名称，默认按钮为“取消”。确认后移除所选实时生成器及其直接连接的生成网格，Ctrl+Z 可整体撤销，也可重做。

源曲线、共用该路径但未选中的辫子、已提取的 XGen 导向和根面、已烘焙的独立网格会保留。资产组中额外放入的其他对象也会保留；此时含这些对象的组可能继续存在。Ramp 区域的“删除所选点”仍只删除分布曲线控制点。

删除要求 Maya 已启用撤销。引用、锁定、实例化或归属不明确的对象会在操作前提示处理，不强行解除保护。确认期间目标被删除或归属改变时，需要重新选中并确认。

## 造型参数

| 参数 | 含义 |
| --- | --- |
| 固定节距 | 节距越小，编织越密；拉长路径时增加周期。长度数值按 cm 解释。 |
| 固定周期 | 保持整条曲线的总编织周期数；拉长时节距变长。切换密度模式会按当前长度换算。 |
| 整体尺寸 | 同时缩放三股分布和发束截面。 |
| 辫子扁平度 | 调整整个编织的厚度方向幅度。 |
| 单股粗细／扁平度 | 调整单股截面的大小与椭圆比例。 |
| 尺寸分布 | 横轴为归一化弧长，根部 0、末端 1；纵轴为尺寸倍率，默认全程 1。 |
| 末端大小 | 编辑尺寸 Ramp 最后一个控制点，不额外叠加第二次渐细。 |
| 整体朝向 | 整条编织截面绕主路径转动。 |
| 局部旋转 | 随归一化弧长改变朝向，数值为角度，默认全程 0°。 |
| 编织相位 | 改变交叉节奏的起始位置，位于高级设置。 |

两条 Ramp 均支持添加、删除控制点及调整位置、数值、插值方式。多选时编辑其中一条 Ramp，会把该 Ramp 应用到所选辫子，不改变另一条 Ramp 或其他参数。

局部旋转示例：设置 `(0, 0°)`、`(0.5, 90°)`、`(1, 0°)`，实现两端不转、中段转 90°。

## 模型精度与形状边界

自动纵向细分考虑编织周期数与路径弯曲程度；手动模式直接指定纵向分段。截面边数独立调整，范围 3–64，默认 12。

修改精度会重新计算几何、UV 和平滑法线，保留三股模型对象及对象级材质关联。逐面材质和组件选择依赖面编号，拓扑改变后不能保证原有对应关系。

纵向上限为 8192 段，导向采样上限为 8193 点。自动要求超限时，降低编织密度或改用合适的手动精度。较粗发束、极小节距或急弯可能相交，本版没有碰撞求解。

根部参考方向在创建或显式重新绑定时保存，随源对象变换；重建保留该参考。根切线相对于参考方向反转约 180° 属于极端情况，应平滑路径并检查朝向。

## XGen 源导向与烘焙

定型后点击“提取 XGen 导向”。每条辫子创建一个新快照组，包含三个股组，每股 9 条连续开放曲线：中心 1 条、周围 8 条。方向从主曲线起点到终点。可同时为每股创建一个具有 UV 的根部圆盘。

导向采样与模型细分独立。提取结果没有生成节点的实时连接，后续调参不会修改已有导向；再次提取会创建新组，不覆盖旧结果。

根部尺寸为 0 时无法创建有效根盘。工具会在创建快照前提示，可以增大根部尺寸或取消根部面选项。不带根部面时，允许提取根部收拢到同一点的源导向。

这些结果是供 XGen 转换的源曲线，尚不是 XGen Description。实际使用时应按三股分别处理，避免跨股插值破坏交叉结构。本工具不设置毛发密度、材质或 UE Groom 导出，相关最终效果不包含在插件功能验收中。

“烘焙独立网格”会产生不依赖插件的模型副本，并保留实时辫子。独立导向和烘焙模型可以导出到不加载 BraidTools 的场景。

## 常见问题

| 提示或现象 | 处理 |
| --- | --- |
| 解压后没有 `.mll` 或安装器 | 使用页首完整学习预览 ZIP，解压全部内容；Code → Download ZIP 是源码快照。不要遗漏 `BraidTools.runtime.json`，安装器用它校验运行文件。 |
| 缺少当前 Maya 年份的插件 | 本安装包包含 2022–2026 五版；2023／2024 为仅编译验证的兼容预览。核对完整解压内容，不要复制其他年份的 `.mll` 代替。 |
| Maya 提示脚本未获许可 | 确认下载来源后，按 Maya 的安全提示处理；安装器不会替用户关闭安全机制。 |
| 无法导入 `braidtools` | 检查顶层 `.mod` 与包文件夹是否并排，路径是否符合实际用户目录；重启 Maya 后重试。 |
| 已加载另一个目录的插件／脚本 | 保存工作并重启 Maya，再使用一个完整安装目录。 |
| Maya 2022 出现 Python 语法错误 | 确认使用 Python 3 模式；Python 2 不受支持。 |
| 无效选择 | 选择开放 NURBS 曲线；闭合路径不受支持。 |
| 源曲线缺失 | 使用“重新绑定路径…”明确指定新对象；同名对象不会自动接管。 |
| 零长度、零切线或 180° 反转 | 调整或重建路径，恢复有效方向。 |
| 节点 ID 冲突 | 停止加载冲突的组合，查看 Script Editor；不要随意改 ID 绕过冲突。见 [NOTICE.txt](../NOTICE.txt)。 |
| `.mll` 无法替换 | 关闭所有加载该文件的 Maya，再替换完整包。 |

源码编译、测试范围与注册 ID 正式构建说明见[项目首页](../README.md)。Maya 的用户路径及模块规则见 [Autodesk 路径变量](https://help.autodesk.com/cloudhelp/2026/ENU/Maya-EnvVar/files/GUID-228CCA33-4AFE-4380-8C3D-18D23F7EAC72.htm)和[模块路径说明](https://help.autodesk.com/cloudhelp/2022/ENU/Maya-SDK/Distributing-Maya-Plug-ins/DistributingUsingModules/Maya-module-paths-folders-and.html)。
