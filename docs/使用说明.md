# BraidTools 使用说明

本文对应开发预览版，源码采用 MIT 许可证。公开节点 ID 尚待申请，二进制尚未公开发布。版本状态以[项目首页](../README.md)为准。

## 环境与安装方式

适用平台为 Windows x64。当前 Maya 2022、2025、2026 各有独立本地构建，并各通过 18 项隔离功能验收；三版的模块自动发现、完整面板构建及离屏 Ramp 编辑等补充检查也通过。2023、2024 未验证且无二进制。Maya 2022 必须使用 Python 3 模式。当前多版本包的真实 GUI 拖动、视口交互与长时间运行尚未逐版复验。

每个年份使用 `plug-ins/<年份>/braidTools.mll`。不要把其他年份的 `.mll` 复制或改名到缺失的目录中。Python 面板自动使用 Maya 自带的 PySide2／PySide6。

### 长期安装

以下是通用手动安装步骤。安装会让该用户的 Maya 在以后启动时发现插件脚本和对应年份的二进制；面板不会自动弹出。无需写入 Maya 程序安装目录，无需更改 `Maya.env`、`userSetup.py` 或系统环境变量。

例如 `C:/Program Files/Autodesk/Maya2026/modules` 确实是 Maya 2026 的有效模块目录。本说明采用用户目录，便于一个包供多个 Maya 年份使用，并避免程序目录写入权限问题。

1. 保存工作并关闭相关 Maya。若已有 BraidTools，先将现有包备份到 Maya 模块搜索目录之外。
2. 在实际 Windows“文档”目录下找到或建立 `maya/modules`，把完整包放入其下名为 `BraidTools` 的文件夹。
3. 将包里的 `BraidTools.mod` 复制到 `modules` 顶层，使它与 `BraidTools` 文件夹并排。包内的文件是待复制的安装描述；其中 `./BraidTools` 相对于复制后的 `.mod` 位置解释。不要只把 `.mod` 留在包内部。
4. 重启对应版本的 Maya，在 Script Editor 的 Python 页签运行下面的打开命令。

```text
Documents/maya/modules/
├── BraidTools.mod
└── BraidTools/
    ├── BraidTools_Open.py
    ├── scripts/
    │   └── braidtools/
    └── plug-ins/
        ├── 2022/braidTools.mll
        ├── 2025/braidTools.mll
        └── 2026/braidTools.mll
```

“文档”被重定向或使用了自定义 `MAYA_APP_DIR` 时，应使用实际 Maya 用户目录。安装路径不必与本示意图完全相同，但 `.mod` 和包目录的相对位置必须一致。源码仓库不含二进制，使用源码安装时先编译所需年份。

打开命令会加载对应版本的插件并显示面板：

```python
import braidtools
braidtools.show()
```

可编辑场景依赖 `braidToolsGenerator`。重新启动后，先打开工具，再打开含该节点的场景。把上述命令保存为自己的 Shelf 按钮属于可选操作，会修改用户的 Shelf 设置，本文不自动执行。

### 临时试用

将完整包里的 `BraidTools_Open.py` 拖到 Maya 视口。它按当前 Maya 年份寻找 `.mll`，为本次会话添加脚本路径并打开面板。重启后需再次打开，不构成长期模块安装。

如果当前会话已经从另一个目录导入 BraidTools，工具会提示冲突。保存工作并重新启动 Maya，再打开目标包，避免混用新旧脚本和二进制。Maya 的脚本安全提示应在确认来源后由用户处理。

### 更新与停用

更新时关闭相关 Maya，保留旧版本备份，替换完整包及顶层 `BraidTools.mod`，然后重新启动。不要在插件已经加载时覆盖 `.mll`。

停用时关闭 Maya，将顶层 `BraidTools.mod` 与 `BraidTools` 文件夹一起移出模块搜索目录。只改 `.mod` 扩展名不是可靠的停用方式。仍含生成节点的场景需要保留匹配插件，或先保存导向与烘焙模型的独立副本。开发节点 ID 更换为注册 ID 前后，应使用经过验证的迁移方式，不能假定直接替换兼容。

## 生成与编辑

选择一条或多条开放 NURBS 曲线，点击“从所选曲线创建”。一条路径产生一个独立生成节点、一个资产组和三股模型。再次对同一条路径创建时，会定位已有资产。

选择主曲线、生成模型或资产组，面板读取对应参数。多选时，只把当前操作的参数写入所选辫子，保留其他参数的差异。关闭面板后，几何仍由 Maya 依赖图计算。

移动或缩放主曲线控制辫子路径。输出资产组是坐标容器，变换会被节点补偿；需要整体移动时，移动主曲线，或将路径与输出放到共同父组下。不要单独移动生成股的子变换节点。

支持 Maya 原位 Rebuild Curve 和工具内重建。若重建改变了路径，辫子也会跟随变化；重建不承诺保留原形。关联依据源对象身份维护，不依赖名称猜测。删除源对象后，选择资产并点击“重新绑定路径…”，再指定新的开放曲线；弹窗会固定正在编辑的资产。

创建、一次参数操作、工具重建、重新绑定、导向提取和烘焙均可撤销。一次批量操作按一次撤销处理。

## 造型参数

| 参数 | 含义 |
| --- | --- |
| 固定节距 | 节距越小，编织越密；拉长路径时增加周期。长度数值按 cm 解释。 |
| 固定周期 | 保持整条曲线的总编织周期数；拉长时节距变长。切换密度模式会按当前长度换算。 |
| 整体尺寸 | 同时缩放三股分布和发束截面。 |
| 辫子扁平度 | 调整整个编织的厚度方向幅度。 |
| 单股粗细／扁平度 | 调整单股截面的大小与椭圆比例。 |
| 尺寸分布 | 横轴为归一化弧长，根部 0、末端 1；纵轴为尺寸倍率，默认全程 1。 |
| 末端大小 | 编辑尺寸 Ramp 最后一个控制点，不额外叠加第二次渐细。 |
| 整体朝向 | 整条编织截面绕主路径转动。 |
| 局部旋转 | 随归一化弧长改变朝向，数值为角度，默认全程 0°。 |
| 编织相位 | 改变交叉节奏的起始位置，位于高级设置。 |

两条 Ramp 均支持添加、删除控制点及调整位置、数值、插值方式。多选时编辑其中一条 Ramp，会把该 Ramp 应用到所选辫子，不改变另一条 Ramp 或其他参数。

局部旋转示例：设置 `(0, 0°)`、`(0.5, 90°)`、`(1, 0°)`，实现两端不转、中段转 90°。

## 模型精度与形状边界

自动纵向细分考虑编织周期数与路径弯曲程度；手动模式直接指定纵向分段。截面边数独立调整，范围 3–64，默认 12。

修改精度会重新计算几何、UV 和平滑法线，保留三股模型对象及对象级材质关联。逐面材质和组件选择依赖面编号，拓扑改变后不能保证原有对应关系。

纵向上限为 8192 段，导向采样上限为 8193 点。自动要求超限时，降低编织密度或改用合适的手动精度。较粗发束、极小节距或急弯可能相交，本版没有碰撞求解。

根部参考方向在创建或显式重新绑定时保存，随源对象变换；重建保留该参考。根切线相对于参考方向反转约 180° 属于极端情况，应平滑路径并检查朝向。

## XGen 源导向与烘焙

定型后点击“提取 XGen 导向”。每条辫子创建一个新快照组，包含三个股组，每股 9 条连续开放曲线：中心 1 条、周围 8 条。方向从主曲线起点到终点。可同时为每股创建一个具有 UV 的根部圆盘。

导向采样与模型细分独立。提取结果没有生成节点的实时连接，后续调参不会修改已有导向；再次提取会创建新组，不覆盖旧结果。

根部尺寸为 0 时无法创建有效根盘。工具会在创建快照前提示，可以增大根部尺寸或取消根部面选项。不带根部面时，允许提取根部收拢到同一点的源导向。

这些结果是供 XGen 转换的源曲线，尚不是 XGen Description。实际使用时应按三股分别处理，避免跨股插值破坏交叉结构。本工具不设置毛发密度、材质或 UE Groom 导出，相关最终效果不包含在插件功能验收中。

“烘焙独立网格”会产生不依赖插件的模型副本，并保留实时辫子。独立导向和烘焙模型可以导出到不加载 BraidTools 的场景。

## 常见问题

| 提示或现象 | 处理 |
| --- | --- |
| 缺少当前 Maya 年份的插件 | 获取该年份的合法发布包，或用对应 SDK 编译；当前 2023／2024 没有现成产物。 |
| 无法导入 `braidtools` | 检查顶层 `.mod` 与包文件夹是否并排，路径是否符合实际用户目录；重启 Maya 后重试。 |
| 已加载另一个目录的插件／脚本 | 保存工作并重启 Maya，再使用一个完整安装目录。 |
| Maya 2022 出现 Python 语法错误 | 确认使用 Python 3 模式；Python 2 不受支持。 |
| 无效选择 | 选择开放 NURBS 曲线；闭合路径不受支持。 |
| 源曲线缺失 | 使用“重新绑定路径…”明确指定新对象；同名对象不会自动接管。 |
| 零长度、零切线或 180° 反转 | 调整或重建路径，恢复有效方向。 |
| 节点 ID 冲突 | 停止加载冲突的组合，查看 Script Editor；不要随意改 ID 绕过冲突。见 [NOTICE.txt](../NOTICE.txt)。 |
| `.mll` 无法替换 | 关闭所有加载该文件的 Maya，再替换完整包。 |

源码编译、测试范围与公开发布条件见[项目首页](../README.md)。Maya 的用户路径及模块规则见 [Autodesk 路径变量](https://help.autodesk.com/cloudhelp/2026/ENU/Maya-EnvVar/files/GUID-228CCA33-4AFE-4380-8C3D-18D23F7EAC72.htm)和[模块路径说明](https://help.autodesk.com/cloudhelp/2022/ENU/Maya-SDK/Distributing-Maya-Plug-ins/DistributingUsingModules/Maya-module-paths-folders-and.html)。
